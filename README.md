# Rich Snippet Pro for WooCommerce

Generates advanced rich snippets for archives and single products automatically, with WPML and custom fields support.

## Description

This plugin automatically generates advanced rich snippets for WooCommerce archives and single products. It supports WPML for multilingual sites and allows you to use custom fields to enrich your rich snippets.

## Installation

1.  Upload the plugin files to the `/wp-content/plugins/` directory, or install the plugin through the WordPress plugins screen directly.
2.  Activate the plugin through the 'Plugins' screen in WordPress.
3.  Use the 'Settings' -> 'Rich Snippet Pro' screen to configure the plugin.

## Frequently Asked Questions

### What are rich snippets?

Rich snippets are Google search results that show extra information, such as ratings, prices, and availability. They can help your products stand out in search results and attract more customers.

### How do I use the plugin?

The plugin works automatically out of the box. You can configure the settings in the 'Settings' -> 'Rich Snippet Pro' screen.

### How do I use custom fields?

The plugin supports a number of custom fields that you can use to enrich your rich snippets. You can find a list of supported custom fields in the plugin's settings screen.
